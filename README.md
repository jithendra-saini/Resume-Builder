Resume Builder
> HTML • CSS • JavaScript

A web-based application that helps users create and customize professional resumes easily.
- Creating and formatting a professional resume manually can be time-consuming.
- Develop a simple web application to make resume creation easier.
- Built a responsive Resume Builder using HTML, CSS, and JavaScript with customizable resume sections and user input handling.
- Enabled users to quickly create and customize a structured professional resume through a simple web interface.
